# Reglas del proyecto

Todo avance debe documentarse en español junto con el cambio que lo produce.

- Antes de finalizar un avance, actualizar docs/BITACORA.md con fecha real, propósito, archivos o funciones cambiadas, validación realizada, resultado y pendientes.
- Mantener docs/ENTREGABLES.md y docs/BACKLOG.md de acuerdo con el estado real.
- Relacionar requisitos del PRD con implementación y pruebas en docs/TRAZABILIDAD.md.
- Actualizar el README y los manuales cuando cambien instalación, configuración o uso.
- Registrar decisiones relevantes en docs/DECISIONES.md.
- Documentar pruebas ejecutadas y fallos; nunca afirmar validación que no se realizó.
- No inventar entrevistas, aprobaciones, capacitación, resultados, firmas o actividad retrospectiva.
- No versionar .env, secretos ni datos personales reales. Usar datos simulados.
- Cada commit debe representar cambios reales e incluir su documentación pertinente. No exigir aprobación de Juan o Edgar para desarrollar.
